# International Peace Group

A responsive, editorial-style website for the International Peace Group, focused on promoting peace, human rights, conflict resolution, and community initiatives.

## Run locally

The site is fully self-contained and can be opened directly via `index.html`. For the Vite development workflow, install dependencies and run:

```bash
npm install
npm run dev
```

The page uses remote Unsplash imagery and Google Fonts for its visual assets.
